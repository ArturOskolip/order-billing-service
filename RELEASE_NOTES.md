# Release Notes v1.1.0

Основні зміни у версії v1.1.0 порівняно з v1.0.0:

## Added
* Додано спеціальний тариф доставки `80.0` для міста `"Kyiv"`.
* Додано явний параметр ставки податку `tax_rate` (зі значенням за замовчуванням `0.20`) у функцію `process_standard_invoice`.
* Додано дві окремі функції (`process_standard_invoice` та `process_tax_exempt_invoice`) замість спільної.

## Changed
* Коефіцієнт доставки за вагу збільшено з `12.0` до `15.0` за кілограм.
* Виконано перехід до Data Coupling у файлі `billing.py` (прибрано зайві залежності між функціями).

## Breaking Changes
* Змінено сигнатури функцій розрахунку: `calculate_delivery_cost` тепер приймає рядок `city` замість об'єкта `CustomerProfile`.
* Видалено глобальну змінну `GLOBAL_TAX_RATE`.
* Видалено стару функцію `process_invoice` та прапорець `mode_flag`.
